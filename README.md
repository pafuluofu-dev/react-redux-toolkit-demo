# RTK Modern Redux App

A small React application built with Vite and Redux Toolkit to demonstrate modern Redux patterns in a user management flow.

**Live demo:** https://pafuluofu-dev.github.io/react-redux-toolkit-demo/

## Features

- Add and remove users from a list
- Display selected user details
- Manage state with Redux Toolkit slices and a root reducer
- Built with React and Vite for a fast development experience

## Tech Stack

- React
- Vite
- Redux Toolkit
- React Redux

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Project Structure

- src/App.jsx — main app component
- src/store.js — Redux store configuration
- src/rootReducer.js — root reducer setup
- src/features/usersList/ — user list slice and UI components
- src/features/userDetails/ — selected user details UI
